1 · 지점 / 테마

테마를 고르면 난이도/장르/러닝타임이 나타납니다.

2 · 날짜

테마 선택 후 '오픈 창 스캔'을 누르면 날짜별 가능 슬롯 수가 나옵니다.

3 · 시간대 (하나만 선택)

날짜를 선택하세요.
이미 예약이 열린 날짜 / 지난 날짜는 대상에서 뺍니다(이미 오픈으로 표시, 클릭 불가). 아직 오픈 전인 날짜(보통 7일 이후)의 시간대만 고를 수 있고, 오픈 시각에 enable=Y 로 바뀌는 그 순간 자동 제출됩니다.
날짜를 고르면 그 날짜가 예약 열리는 시각이 자동으로 세팅됩니다 (지점별 오픈 시각 출처: reservation.php).
reCAPTCHA '로봇이 아닙니다' 는 여전히 사람이 클릭합니다. 토큰이 생긴 뒤 좌표/약관/예약자/금액을 검증하고 버튼을 1회 누릅니다(기본 off).
위 이름/휴대폰 은 reservation2 폼에 자동으로 채워질 값입니다(브라우저에 기억). 인원은 사이트 기본값, 폴링 종료 60초는 고정. Step1 화면은 통째로 생략하고 reservation2.php 로 직접 POST 하며, reCAPTCHA 체크는 직접 해야 합니다. 위 '캡차 통과 후 자동 클릭'을 켜면 그 직후 '예약하기' 까지 자동으로 누릅니다.
